# Mission

## What
Dominar o **dlt (data load tool)** — a biblioteca open-source Python para ingestão de dados — a ponto de explicar cada mecanismo com precisão, sem depender da memória de ter usado.

## Why
A proposta de uma palestra sobre dlt foi aceita para a Python Brasil 2026. O palestrante já tem experiência prática com dlt em produção (integração de múltiplos tipos de fontes — APIs, arquivos, bancos legados) e viu os problemas que a ferramenta resolve. Antes de elaborar o material, é preciso dominar a biblioteca a fundo — é isso que este estudo faz.

## Success criteria
- Entender a anatomia completa do dlt: origem, empresa, ecossistema, licença, comunidade
- Dominar cada componente central: `resource`, `source`, `pipeline`, `destination`, `transformer`
- Compreender mecanismos avançados: schema inference, normalização de dados aninhados, carregamento incremental, schema contracts
- Conseguir explicar como dlt se encaixa numa stack de dados moderna (DuckDB, dbt, Airflow, Dagster)
- Ter exemplos de código funcionais para cada conceito estudado
